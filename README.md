SEP005 <- Ashes io
-----------------------

Basic package to import data generated by Ashes.txt files compliant with
SDyPy format for timeseries as proposed in SEP005.

Installation
------------
Regular install:
```
pip install sep005-io-ashes
```
For developers:

After cloning into your folder
```
pip install -e .[dev]
```
